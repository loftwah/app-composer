check, verified failed checks block later stages, verified stage ordering, and
inspected a synthetic target before resolving uncertain pipeline and hook
operations. Confirmed duplicates produced one effect. Seventeen malformed,
missing/wrong scope or authentication cases produced no additional effects.

Two actionable defects were found. The bundled exercise suppressed uncertain
replays without demonstrating target inspection, despite claiming reconciliation.
The pipeline also discarded the failure category. The maintained examples now
inspect an explicit local target receipt before finishing an uncertain operation,
assert one effect without replay, and retain only allowlisted redacted failure
codes. Arbitrary exception messages are not exposed. `node examples/exercise.mjs`
exercises those fixes in the rebuilt archive.

The evaluated change is included in the new kit under `examples/field-notes/`,
with its patch, working instructions, provenance and actual phone/desktop captures.
Its provenance identifies the older input archive separately from the rebuilt
archive containing the result. Python 3.10+ is optional for that example; the
standard Node checks acquire no Python dependency.

Both agents selected already installed supported Python interpreters after
checking the system default. They used unused loopback ports, removed their owned
temporary roots and stopped their own services/browser sessions. No owner
workspace, unrelated process, provider account, mail, payment or production
record was altered. Bounded receipts remain in the release evidence; #11 owns
source, archive, deployment and fresh production verification.
