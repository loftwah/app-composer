# Writing and interface standard

Reviewed 14 October 2026. Say what the person can do and what happened. Use specific examples and supported claims. Avoid inflated slogans, empty adjectives, decorative dashboards, invented popularity and boilerplate promises. The collection’s real content leads the page.

Use semantic controls, visible keyboard focus, responsive spacing and native interactions. Confirm actual builds and rendered journeys; a detector score, copied file or successful HTTP request is not product acceptance. Add relevant public metadata and original artwork only when this project has its own verified public identity. Preserve confidentiality and source/licence notices.
