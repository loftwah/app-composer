# Content site

Reviewed 14 October 2026. This project gives an owner native EmDash editing and visitors a page of explicitly published entries. The selected content structure lives in src/content-model.json. Draft editing/publication is owned by EmDash; the page applies the model’s optional display conditions without claiming native editor parity. No public submission endpoint is supplied.

Get Ready prepares the actual environment; the application runs independently. Initial owner setup, the final brand, repository, cloud account, domain, privacy and release decisions belong to this project, not the source of its template.
