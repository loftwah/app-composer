# Portfolio analytics artwork

The portfolio view and exported cards use the existing public project artwork. Derivatives retain their original imagery and are resized, encoded as JPEG and published under the dated `public/brand/portfolio/` path. Card artwork under `src/assets/portfolio/` has identical bytes and is bundled so card rendering needs no image request. The Music view uses the existing LoftwahFM identity artwork.
