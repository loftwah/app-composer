# Keep it yours — App Composer commercial

The 24-second spot uses [Woodhouse Share artwork](https://woodhouse.loftwah.com/share/app-composer/) for the workshop scenes and the live [Fictional Trail Notes](https://composer.loftwah.com/s/fictional-trail-notes) revision 30 for the product shot. The final four seconds use the approved orange-and-white App Composer artwork from `public/brand/campaign/product-og-20261022b.png`. The film poster uses the existing Make. Keep. Remix. artwork.

ElevenCreative Studio Agent assembled the first cut. It used Veo 3.1 Lite for the drawer opening, Seedance 2.5 for the blueprint reveal, Eleven v4 for Brendan’s narration, Sound Effects v2 for the drawer and latch, and Eleven Music v2.5 for the score. The lower-cost opener and premium reveal were quoted together at 15,183.33 Starter credits. The chat showed 18,655 credits after the editing pass. The six generated originals were imported into the private Composer launch-artwork project in Media Studio.

Chrome blocked the Studio MP4 download redirect. The web delivery was finished locally from the six originals, with a real capture of Trail Notes, cut points at measured narration pauses, a hold on the final reveal frame, and a same-origin VTT track and descriptive transcript. The public film is 24 seconds, 1280 × 720, H.264/AAC, and approximately 5.4 MB. Integrated loudness measured −18.9 LUFS with a −4.3 dBFS true peak.

## Benchmark for Media Studio

- Start with a short brief, exact reference frames, narration, and the existing brand card. Make the first edit watchable on an editable timeline with all assets in the project library.
- Quote by shot, model, and duration before dispatch. Here, replacing one premium generation with a lighter model and shortening the reveal reduced the initial two-shot estimate from about 47,774 to 15,183 credits.
- Keep model output editable and reusable. Retain original takes and separate narration, music and effects so a pacing or mix change can reuse the approved motion.
- Show caption and approximate edit timing clearly, then let a reviewer verify against the actual audio. Offer a reproducible export with working downloads for the cut and separate assets.
