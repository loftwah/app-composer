# Collect from an app-owned visitor book

The existing native **Manage mini-apps → Linkarooie** panel adds an explicit workspace, saved stack/book and approved-contribution selector. It remains behind EmDash `plugins:manage` and the existing global role-50 boundary. Within that boundary, only workspace owners and editors may use the source; workspace membership does not grant global administration or Access admission. Legacy global photos, cards and settings retain their separate controls.

The server derives the resource and activated configuration from the selected saved binding and requires its exact stack revision. It verifies current Guestbook account, environment, target and reviewed source, current visibility and item approval, plus Linkarooie's exact reviewed build and `providerSources` v1 descriptor. Source-bearing writes use fixed server credentials and source/target proof headers; the browser cannot supply URLs, tokens or source revisions. Old reviewed releases show an unsupported message. No runtime pin is advanced by adding the panel.

`collection-sources`, `collection-items` and `collection-check` are read-only actions on the existing authenticated mini-app read route. `feature-resource` is the write action; it requires workspace, stack, instance, expectedRevision and item. Membership and the exact saved stack/binding are rechecked after remote awaits, immediately before dispatch. This cannot cancel an app request that was already dispatched before later membership revocation. Composer never edits that draft, publication or app moderation to collect a contribution.

Confirmed receipts contain the exact resource/configuration/item reference and stable app-owned card ID. Transport failures, incompatible or lost acknowledgements remain unknown. The panel retains the reference across app switches, blocks another collection, and exposes **Check saved source reference**. This checks the current verified app export, without dispatching a write. Its resource must still belong to the authorized workspace and exact account/environment/target, including after a changed binding or deleted stack. A matching reference confirms its current saved card. An absent reference stays unknown because a card could have been deleted after commit; unavailable or malformed reads never prove safe retry. Other local settings, card and profile drafts stay in place.

Guestbook continues to own eligibility and media. Linkarooie rechecks every public render and export; hide/delete/visibility revocation removes source content rather than exporting copied fields. This panel does not provide private source media, moderation, analytics, new accounts or invitation delivery. The app's forward `0002_scoped_sources.sql` migration and exact app release are separate operator/release gates; no Composer migration is required.
