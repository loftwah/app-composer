## Copied-source boundary

Only disposable copies change. The reused lifecycle selects supported EmDash native authentication instead of the production Access wrapper and removes email delivery. The extra platform qualification seam changes both copied `src/plugins/stacks.ts` and `src/plugins/members.ts` factories to supply `PLATFORM_PUBLIC_FETCH` through a fixed `PLATFORM_PUBLIC_PAGES` self service binding. Requests reach the actual local `/s` and mounted app handlers without owner headers. Browser/imported inputs cannot select the endpoint or any credential. Both native creator requests and delegated member requests use this fixed binding; a missing binding throws instead of falling through to global public fetch. Preflight records each exact factory patch and its original/derived SHA-256; the run checks both copied factory hashes before browser admission. This establishes local route verification separately from the production public edge.

Receipts include the original and derived lifecycle hashes, exact copied factory patch, copied authentication configuration and entry hashes, temporary source tree identity, independent app pins, native user roles and bounded operation results. ## Commands

After exact app pin promotion and integration, read-only preparation checks source pins, existing dependencies, exact patch sentinels and port availability. It starts no workerd/browser and makes no admission claim:

```sh
node labs/platform/native-run.mjs prepare \
  --guestbook /path/to/reviewed-clean-guestbook \
  --showcase /path/to/reviewed-clean-showcase
```

After the shared host validation reservation is handed over, run the same selection with `run --admitted`. Do not nest a second reservation. An existing installed Playwright module can be selected with host-only `--playwright /absolute/path/index.mjs`, and an existing probe with `--ffprobe /absolute/path/ffprobe`; no package installation is attempted. Default evidence is ignored `output/platform-native/receipt.json`, bounded screenshots and per-actor raw videos. The distinct `output/platform-native/local-root` pointer must be absent after successful cleanup.
