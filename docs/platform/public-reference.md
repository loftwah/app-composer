# Public platform reference

Reviewed 23 October 2026, Australia/Melbourne.

`/platform` is a reading surface within Composer’s existing transit/interchange
visual language. It explains the business decision before the runtime details,
then connects Get Ready, Init, native EmDash administration and independently
owned applications. The approved Composer mark, Space face and semantic palette
come from `Base.astro` and the existing global tokens; no new artwork or shared
asset variant is introduced.

## Page responsibilities

- A readable authority/runtime route shows people, Composer policy, the trusted
  runner and application capability as different boundaries.
- The hosting comparison distinguishes inspected runtime, provider documentation,
  candidates and remaining target-specific qualification.
- The illustrative browser policy explorer has four outcomes. Membership denial
  precedes runtime/location checks; unsupported requirements remain intact;
  exceptions require review; ordinary supported work can fit standing policy.
- Six permission domains remain separate: enterprise admission, EmDash,
  Composer, delivery, runtime and application-user access.
- The resource lifecycle connects ownership through request, authorisation,
  delivery, operation, recovery and retirement.
- Fourteen named integrations link primary documentation and explain their jobs;
  the full authentication/network/failure contracts live in `integrations.md`.
- The regional flow separates HTTP execution, code/secrets, data/media and
  telemetry/support. Supplier assessment is separate from customer acceptance.

The explorer has no network requests, persistent storage, account discovery,
credentials or execution effect. Its fictional choices are not a request and do
not reuse or change the real server’s authority. Without JavaScript its visible
explanation and full rule alternative remain readable. All diagrams are semantic
HTML with text, not image-only or colour-only information. Tables have captions,
column/row headers and wrapping content; their focusable labelled regions allow
horizontal navigation when user text sizing requires it.
