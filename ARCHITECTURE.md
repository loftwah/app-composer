# Architecture
Reviewed 13 October 2026.

Composer is an Astro/EmDash Cloudflare Worker. EmDash owns catalogue descriptions and documentation in its own D1/R2. The independently deployed Guestbook and Showcase own separate GitHub histories, D1 state and storage. Composer mounts separately pinned integrated Worker services under one origin. Standalone upstream deployments cannot change this consumer code. Each integrated service uses the app-owned D1/R2, so current moderation remains shared while executable versions stay pinned. Promotion validates exact reviewed source pins and explicitly deploys the integrated services. The Showcase asks a versioned generic item provider for current eligibility; it never copies a private image or treats saved approval as permission. Each service remains deployable without Composer or Woodhouse.

External Codex is the execution adapter. Get Ready checks its real workspace through a repo command, not browser guesses. Init and Explorer share a versioned specification. The trusted deployer uses existing scoped runtime credentials; public HTTP cannot trigger builds or deploys. Only reviewed authored repositories are executable. The local-tool installer also accepts an unchanged personal private copy at the actual maintained source SHA, with fresh GitHub owner/permission and full byte checks; it installs from isolated reviewed dependency inputs. This installation operation never applies Init configuration or runs a cloud deployment; owned-copy release actions remain unsupported. Unknown registries are inspected as JSON, never installed or executed automatically. Local build does not claim to sandbox arbitrary downloaded source.

Owner API tokens live in runtime secrets. Browser writes require explicit owner authentication and same-origin requests. EmDash administrative routes stay closed until Access JWT verification is configured; public read queries remain available. Preview resources are separate. Public demos use fictional seeded content and invitation-only submission; no unbounded anonymous media upload. Portable AI State encrypts locally and never sends a master key or plaintext to a server or model.
