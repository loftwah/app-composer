# The talk

**Title** — From brief to byte

**Abstract** — Start with a finished image. Work backwards through the App, the model and the infrastructure. Run a Worker on your laptop, trace a synthetic request in AI Gateway if you have a funded path, and leave with a repeatable creative workflow you can run on your own account.

**Open with** — “Here’s a print. I want the original file, the brief that made it, and a way to do it again next week. Let’s follow the job.”

## Twenty-minute workshop

- **0–4 min** · Read the original creative brief and identify why the headline reads at feed size.
- **4–8 min** · Run the Worker with the two output formats. Ask attendees to find the line that proves no inference.
- **8–12 min** · Open the local Oyster trial or the public screenshot. Explain App permissions, the Computer folder and how MCP calls an authorised App.
- **12–16 min** · Do one Gateway request on a prepared account. Show the dashboard and how to identify the request. Keep the prompts synthetic and the token out of the recording.
- **16–20 min** · Ask each attendee to remix the brief. Give people a local path and an owned cloud path. Count a locally reproduced response and a separately observed Gateway request as different outcomes.

## If the live call fails

Keep the stage view and this kit on disk. Switch to the local Worker response and label it a rehearsal. Use the historical image receipts to show real generation evidence. If the live request times out, check the dashboard before trying again. Share the exact public docs for the error rather than borrowing somebody’s key or silently swapping account.

## Questions you’ll get

- **Do I need a GPU?** The cloud path sends inference to the chosen provider. Local Oyster rehearsal shows the Apps and MCP without inference.
- **What do I own?** Your accounts, deployment and project files on an owned host. The model provider, pricing and permissions still matter.
- **Do I need all six layers?** A Worker can call a model for a simple function. Add Gateway for routes you want to observe or control. Add Oyster when the App, files and authorised agents need a shared home.
- **Did the poster go through Gateway?** The campaign poster and historical Oyster images have their own provenance. Show an actual dashboard request before claiming Gateway routing.
- **Can I use the speaker’s credits?** Everyone can get the kit. Live calls use the attendee’s own approved access and budget.
