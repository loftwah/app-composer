# Prints Desktop workshop prompts

Open prints.loftwah.com and choose Try it. The prompts below work in your own image tool or agent.

## I want to open the app

Build a small contact sheet from three images already in my project. Use the original files. Give me one line of provenance for each, then recommend which should be my lead image and why. Keep the originals byte-for-byte.

## I want to make a poster

Create a 4:5 editorial poster for an imaginary night train called LAST TRAIN HOME. A single cream ticket curls into a coastline on a black station floor. One signal-orange lamp lights the fold. Make the exact words “LAST TRAIN HOME” large enough to read at 300 pixels wide. Use no other lettering. Keep the main object and words inside the middle 80 percent.

## I want my AI agent to help

Use the authorised Prints tool to read the selected library. List up to five images with their filename, dimensions and any recorded brief or model. Pick two with different crops and explain which is better for a link preview. If the library is unavailable, tell me which folder or permission to check. Keep the run read-only.

## I use Shiitake

Read the public project README and draft prints-brief.md in this folder. Write a single image prompt with one visual joke, exactly one headline, a 4:5 feed crop and a 1200×630 link crop. Add a three-item review list for spelling, contrast and credit. Draft the file locally and keep inference off.

[Open the Shiitake quickstart](https://docs.fungi.computer/guides/use-the-terminal/)

## I just want to keep my own files

Write a short offline workflow for keeping the originals of my next three images. Give each one a folder name, a brief.txt with the source and intended use, and a place for one square and one landscape export. Preserve all original filenames and files.

## I’m building with AI

Help me add a POSTER brief to the local workshop Worker. Return a caption and dimensions for feed and link outputs. Include one valid request for each format and one rejected input. Keep the rehearsal deterministic and report zero inference calls. Then list the authorised account settings needed for a separate live Gateway check.
