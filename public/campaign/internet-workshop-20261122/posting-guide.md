## Format and placement

- Instagram has 4:5 feed and square files. Use the cover as a carousel opener. For a story, keep the link sticker outside the headline.
- X and Discord lead with the fastest question or joke. Put context and the link on a separate line. Check each community’s promotion rules before using the Reddit versions.
- LinkedIn pairs the poster with concrete workings, a use case or a release receipt. Ask a question people can answer from experience.
- TikTok and Shorts use 9:16 posters with a caption-safe area. The shot briefs describe production ideas. Where a vertical MP4 is included it is labelled as a motion poster.
- Share detail pages include a public caption, credited post file and alt text. Reopen the posted account and check the actual result before marking a future delivery verified.

## References and intent

- [xkcd’s Compiling](https://xkcd.com/303/) and [Dependency](https://xkcd.com/2347/) informed the dry build-time and maintainer jokes. The artwork, staging and punchlines are original.
- [Know Your Meme’s programming collections](https://trending.knowyourmeme.com/editorials/collections/26-programming-memes-to-debug-your-mind) informed the familiar setup and short reveal. The public artwork uses fictional examples.
- [CERN’s original Web licensing record](https://home.cern/science/computing/the-birth-of-the-web/licensing-web/) supports the year quiz. Use the specific public-domain milestone in the question copy.
- [The Internet Archive memorial for Aaron Swartz](https://www.youtube.com/watch?v=x3Fz1V3LZtw) accompanies the standalone tribute. Keep the post focused on the open web and access to knowledge.
- [Cloudflare Durable Objects](https://developers.cloudflare.com/durable-objects/) supports the educational service reference. Keep the collectible card’s personality fictional.
- [Publishing connections #604](https://github.com/loftwah/app-composer/issues/604) and [Calendar and approvals #663](https://github.com/loftwah/app-composer/issues/663) own live scheduling and account proof.

## What to make in Media Studio next

- A sound-on dial-up museum short. Record an original modem-like motif, subtitle every cue and pair it with a sourced Web history milestone.
- A playable Door trailer. Cut practical door footage into an actual browser capture of the reveal, then export every ending as a GIF or 9:16 clip if the result renderer supports it.
- A Foilbury macro and LoftwahFM sleeve series. Work from approved captures and original audio. Keep a clean music-only master, a captioned end-card version and reusable cover designs.
- A 25-second App Composer release receipt. Put the changed behaviour, exact release and real live action on screen. Teach Studio to keep source links and approved copy with each rendered size.
