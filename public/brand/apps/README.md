# App artwork distribution

Each app owns its illustration, configuration and release. Composer commits local catalogue and launcher derivatives; no independent app fetches Composer artwork at runtime.

18 October2026: dated `*-small-20261018.webp` icons show each app’s specific action. Composer fits a module; Here / there pins a postcard; Link Check exposes a bad contact; Hello sends its first signal; Carry passes its memory capsule. Linkarooie keeps the qualified accepted lime workshop curator and a same-master optical head crop. Dated social cards describe the software with the repaired complete Space Latin font. The other original hero scenes remain unchanged.

Exact prompts and source hashes are in `.artwork/identity-{prompts,exports}-20261018.json`; exports use `.artwork/og/export-optical-icons.mjs` and `.artwork/og/render-card-templates.mjs`. Linkarooie has its own same-master compositor. The shared maintenance command pins the delivered thumbnail hashes and refuses different bytes at an immutable dated filename. The owning apps record their own delivered hashes. These drawings are agent-selected; the owner’s qualified 8/10 Linkarooie acceptance is not blanket approval of every asset.

Old dated assets remain available as historical immutable URLs. Screenshot derivatives under `previews/` are real software captures with their own capture date and must be refreshed from actual deployed UI, never replaced with drawings.

24 October 2026: the complete seven-app launcher also uses Launch Kit's existing `launch-kit-20261023-32.png` (the same delivered bytes as its app-owned `night-signal-icon-32.png`) and `paperwork-icon-20261024.svg`, copied byte-for-byte from Paperwork's existing `public/icon.svg`. These are existing identities, without regeneration or recolouring. The explicit maintainer pins their SHA-256 values and supplies local copies to each app and new generated content projects.
